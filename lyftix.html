Lyftix

A full-stack Self-Hosted Personal Analytics Platform A full-stack personal designed to consolidate workouts, GitHub activity, coding sessions, daily wellbeing and Linux system metrics into interactive dashboards with historical trends and cross-domain insights. Built with a modular Spring Boot backend, React and PostgreSQL, the application combines manual data entry with automated Python ingestion workers, recoverable data collection and authenticated APIs. Deployed on a personally configured physical Ubuntu Linux server, Lyftix operates across 11 containerized services with isolated networking, private HTTPS access, automated testing and continuous integration, and production monitoring through Prometheus and Grafana.
